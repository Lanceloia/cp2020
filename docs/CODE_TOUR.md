# CP2020代码与历史导览

## 从源码到IR

先读[main.c](../Lab/Code/main.c)：打开显式输入，执行词法／语法，再进入语义遍历；
有第二个参数时把后续输出重定向到指定文件。
[syntax.y](../Lab/Code/syntax.y)定义AST构造，
[symtab.c](../Lab/Code/symtab.c)维护符号与类型，
[semantic.c](../Lab/Code/semantic.c)完成语义检查并输出IR。

阅读时可追一个带函数、局部变量与条件分支的输入，观察四类问题：

1. 标识符在哪里定义、在哪里找到？
2. 表达式类型与数组／结构体类型怎样比较？
3. 条件表达式怎样生成跳转与标号？
4. 参数、返回值与字段地址怎样成为IR操作数？

`semantic.c`同时承担检查与IR输出，这是当时课程实现的组织选择，
适合讨论“一次遍历完成”与“先构建受检IR、再输出”的取舍。
